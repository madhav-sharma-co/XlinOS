# Packaging

This directory will contain XlinOS package definitions, kernel artifact integration metadata and image composition manifests.

The base distribution and package manager are not selected. Do not add package recipes that assume an unapproved userspace. The first packaging decision must document package provenance, signature verification, version pinning, update policy and licence handling.
