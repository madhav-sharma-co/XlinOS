# Build scripts

Build and image scripts will live here. Scripts must fail clearly on missing prerequisites, avoid modifying the host, use pinned and verified inputs, keep generated files under ignored output directories, return non-zero on failure and support clean rebuilds.

No image-building command is available yet.
